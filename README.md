### ⚙️ Systems & IT Operations

My core daily work revolves around connecting corporate platforms, architecting enterprise service workflows, and automating processes end-to-end:

- 🎯 **Freshservice & ITSM/ESM:** Managing, scaling, and optimizing the platform to continuously improve usability across all company departments. Designing complex workflow automators, custom objects, Liquid syntax parsing, bulk ticket actions, and automated reporting via API.
- 🔌 **Enterprise API Integrations:** Architecting and maintaining RESTful API integrations, webhooks, and data-sync pipelines across corporate ecosystems. Connecting ITSM modules, databases, and third-party platforms via JSON payload manipulation to eliminate manual bottlenecks and ensure data consistency.
- 🖥️ **Custom GUI Tools:** Building standalone, multi-threaded desktop applications (`.exe`) with Python and `CustomTkinter` to streamline API testing, pagination, and daily internal workflows for the IT team.

### 🚀 Featured Solutions & Architecture

Even when scripts and workflows live inside private corporate environments, here is a glimpse of what I build and maintain:

- 🧪 **Freshservice API Studio:** Custom multi-threaded Python desktop tool (`CustomTkinter` + `Pandas`) designed to execute, paginate, and test REST API calls with JSON syntax highlighting and automated report extraction.
- 🔐 **Automated Access Governance:** End-to-end provisioning and revocation workflows integrating **Freshservice Automator**, **Custom Objects**, and **Power Automate** via Webhooks, featuring automated retry redundancy and audit logging.
- 🛠️ **Desktop Automation Suite:** Standalone Python executables built with `PyInstaller` for bulk ticket creation from spreadsheets, automated UI routines, and hardware/peripherals sync.
